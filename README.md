# NODEBREAKER

A pixel-art hacking puzzle game for mobile browsers. Explore fictional
servers, find clues, combine them into working credentials, and break in —
before the trace timer catches you.

Play it at **https://habibsyuhada.github.io/nodebreaker/**.

## What it is

- 8 hand-built levels, each teaching a new hacking mechanic (search, decode,
  crack hashes, multi-node pivots, honeypots, privilege escalation, log
  cleanup) on top of the ones before it.
- Every level opens on a short scene showing who gets hurt by the target and
  closes on the payoff — available in English and Bahasa Indonesia.
- No typing anywhere in the game: everything is tap, tap-hold, drag, or a
  preset search chip. Optimized for one-handed portrait play on a phone.
- Installable as a PWA and playable fully offline after the first load. No
  backend, no accounts — all progress lives in the browser's local storage.

See `PROGRESS.md` for the full design brief, architecture notes, and the
build's stage-by-stage history — it's the authoritative source of truth for
this project, kept up to date as work lands.

## Stack

React 19 + TypeScript + Vite, Zustand for state (with `persist` for saves),
Tailwind v4. All visuals are pixel-art canvas sprites and hand-written inline
SVG icons; all audio is generated procedurally with the Web Audio API — the
project deliberately ships with zero external image or audio assets.

## Development

```bash
npm install
npm run dev       # dev server on :5173 — note: no service worker here, see below
npm run build     # tsc -b && vite build
npm run lint      # oxlint
npx tsc -b --noEmit
```

The PWA's service worker (`vite-plugin-pwa`, Workbox `generateSW`) is only
generated by `npm run build` — to test offline behavior or install prompts,
use `npm run build && npm run preview`, not `npm run dev`.

## Deployment

- **Web / PWA**: `.github/workflows/deploy-pages.yml` builds and publishes to
  GitHub Pages on every push to `main`.
- **Android / Play Store**: `.github/workflows/release-play.yml` (manual
  dispatch) wraps the deployed PWA in a Bubblewrap TWA and uploads it via the
  Play Developer API. Config lives in `android/twa-manifest.json`.
